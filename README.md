# UniPay: Clearing

Этот репозиторий принадлежит паре студентов. В нём только выданные лабораторные,
без преподавательских решений и без истории преподавательского репозитория.
Начните с `START_HERE.md`, затем откройте `labs/labNN/TASK.md`.
Выданы те номера, чьи квитанции находятся в `.unipay/issues/`; будущих папок нет.

## Подготовка

Поддерживаются Python 3.10 и 3.13. Создайте окружение: `python -m venv .venv`.
Windows PowerShell: `.\.venv\Scripts\Activate.ps1`.
Linux: `source .venv/bin/activate`.
При запрете активации в PowerShell используйте `.\.venv\Scripts\python.exe`
вместо `python`, не меняя системную политику.

```sh
python -m pip install -r requirements.txt
python check.py lab01
```

Выбранную работу выполняйте в отдельной ветке, затем PR и merge. Нужны
содержательные коммиты обоих участников. Тесты открыты и уже написаны преподавателем.
Начальные падения ожидаемы и перечислены в STARTER-STATE.md; на сдаче они должны
быть исправлены. В ЛР1/ЛР4 зелёные тесты не заменяют рефакторинг и понимание.
Бонус запускается отдельно: `python check.py lab01 --bonus`.

## Следующая лабораторная

Скачанный `unipay.py` используется для всех номеров. В корне своего репозитория:

```sh
python unipay.py --list
python unipay.py 2
```

Номер замените нужным. Скрипт запоминает вариант в `.unipay/course.json`, получает
только опубликованную преподавателем работу и спрашивает подтверждение добавления.
Повтор не сбрасывает решение. Другая редакция или конфликт требуют разбора с преподавателем;
автоматической перезаписи нет. Просмотр без записи: `python unipay.py 2 --dry-run`.
Для первой установки вариант задаётся явно: `python unipay.py 1 --variant card`.

Git status, commit, push и PR выполняйте сами. Для получения материалов не нужны
GitHub-токен, pytest или доступ к преподавательскому репозиторию. Установка pytest
нужна позже для запуска открытых тестов. Скрипт не исполняет загруженный код.
