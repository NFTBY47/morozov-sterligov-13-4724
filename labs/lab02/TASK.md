# ЛР2. Проверки перед добавлением

Вариант: **Clearing**.

## Что дано

Обычное добавление операции в пакет работает, но защита закрытого пакета, валюты, статуса операции и повторного ID пока неполна. Важно выполнить все проверки до изменения коллекции.

## Задание

### Шаг 1. Завершите `ClearingBatch.validate_add(tx)`

Проверяйте условия в таком порядке: пакет имеет статус `OPEN`, иначе `BATCH_CLOSED`; операция имеет статус `APPROVED`, иначе `TRANSACTION_NOT_APPROVED`; валюта операции совпадает с валютой пакета, иначе `CURRENCY_MISMATCH`; `transaction_id` ещё отсутствует внутри пакета, иначе `DUPLICATE_TRANSACTION`.

### Шаг 2. Проверяйте до изменения коллекции

`add_transaction()` должен сначала вызвать `validate_add(tx)` и только после успешной проверки добавить операцию. Наружу коллекция операций возвращается как `tuple`.

Если операция отклонена, состав пакета, его сумма и доступность ID должны остаться прежними.

### Шаг 3. Используйте готовые проверки там, где они уже есть

Закрытие пустого пакета вызывает `EMPTY_BATCH`. Уникальность `transaction_id` между разными пакетами уже проверяет готовая функция сервиса — новое хранилище или второй реестр ID писать не нужно.

## Примеры и границы

- Закрытый пакет не принимает операцию и сохраняет прежнюю сумму.
- USD не добавляется в EUR-пакет; `DECLINED` не добавляется вообще.
- Повтор `TX-1` отклоняется внутри пакета и в другом пакете.
- Неуспешное добавление не занимает ID для следующей корректной попытки.

## Дополнительное задание

**Удаление из ещё открытого пакета.** Добавьте `ClearingBatch.remove_transaction(transaction_id)`. Метод удаляет найденную операцию из `OPEN`-пакета и возвращает её объект, сохраняя порядок остальных.

Для закрытого пакета вызывается `BATCH_CLOSED`, для неизвестного ID в открытом — `NOT_FOUND`. Найдите операцию до изменения списка; ошибка сохраняет пакет. После удаления последней операции пакет пуст и не закрывается (`EMPTY_BATCH`). Это изменение состава пакета, не возврат денег и не удаление из Ledger.

Проверка: `python check.py lab02 --bonus`.
